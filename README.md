
# Student Portfolio Website

A personal student portfolio website developed using HTML, CSS, and JavaScript to showcase my profile, education, technical skills, projects, and contact information.

## 🚀 Features

- Responsive website design
- Home and About Me sections
- Education details
- Technical skills showcase
- Project portfolio
- Contact form with JavaScript validation
- Dark and Light mode
- Mobile-friendly navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

StudentPortfolio/
│
├── index.html
├── style.css
├── script.js
└── README.md

## 💻 How to Run

1. Clone this repository:

   git clone YOUR_REPOSITORY_URL

2. Open the project folder in VS Code.

3. Open `index.html` in your web browser.
